# appserver

Extra setup scripts for an Ubuntu 24.04 application server (Laravel / PHP). They follow the same conventions as the web account manager in the top-level folder: run as root, safe to re-run, and they reuse `lib.sh`.

| Script | What it does |
| --- | --- |
| `install-php.sh` | Installs PHP-FPM with the extensions Laravel needs (MySQL and PostgreSQL drivers included), Composer, Supervisor, git, unzip and a swap file. |
| `install-holding.sh` | Serves a plain "Hello" page for the server's bare IP address and any host name that isn't an account. |

## Usage

On a fresh server, run the top-level setup first (it installs nginx and certbot), then these:

```bash
sudo git clone https://github.com/igunter/ubuntu-app-server-admin.git /ubuntu-app-server-admin
cd /ubuntu-app-server-admin
sudo bash install.sh
sudo bash appserver/install-php.sh
sudo bash appserver/install-holding.sh   # optional
sudo bash webadmin.sh
```

Options for `install-php.sh`, set as environment variables:

```bash
sudo PHP_VER=8.3 SWAP_SIZE=2G bash appserver/install-php.sh
```

## Notes

- Open ports 80 and 443 in the Lightsail firewall. Restrict SSH (22) to your own IP.
- Once `install-php.sh` has run, PHP can be switched on per account from `webadmin.sh` (Edit Account).
- The conf generated by `webadmin.sh` serves `public_html` and returns 404 for unknown paths. It has no front-controller routing and no `public/` document root, so it doesn't suit Laravel pretty URLs yet. Manual edits to generated confs are overwritten, so a Laravel site needs its own conf, created outside the manager.
- The holding page loads the Sansation font from Google Fonts.
- Never commit `.env` files, database passwords or SSH keys. The `.gitignore` covers the common cases.
